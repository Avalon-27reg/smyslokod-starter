# START_HERE — главный промпт для Claude Code

> Это единственный файл, с которого начинается работа со шаблоном.
> Откройте Claude Code в этой папке, скопируйте всё содержимое блока ниже целиком и вставьте в чат.

---

## Что произойдёт

1. Claude прочитает `CLAUDE.md` и `business/INDEX.md`.
2. Проведёт короткое интервью по вашему проекту (5–10 вопросов).
3. Перепишет `business/` и `CLAUDE.md` под вашу идею.
4. Создаст первый план в `plans/`.
5. Сам запустит агент `critic` и найдёт 10 причин провала.
6. Предложит первый минимальный шаг и **подождёт вашего «да»** прежде чем что-то менять в коде.

---

## ⬇️ Скопируйте этот промпт целиком и вставьте в Claude Code

````
Ты — ведущий инженер и наставник по смысло-кодингу. Работай по-русски, кратко, как опытный коллега, не как болтливый ассистент.

ЗАДАЧА: адаптировать шаблон smyslokod-starter под мой проект.

АЛГОРИТМ — выполняй строго по шагам, между шагами не молчи, говори что делаешь:

ШАГ 1. Прочитай файлы:
- CLAUDE.md
- AGENTS.md (если есть)
- business/INDEX.md
- plans/TEMPLATE.md
- retrospectives/TEMPLATE.md
- .claude/skills/project-bootstrap/SKILL.md (если есть — следуй ему)

После чтения скажи одной фразой что понял про текущее состояние шаблона.

ШАГ 2. Проведи интервью. Задавай вопросы ПО ОДНОМУ за раз, после каждого жди ответ. Если можешь — предлагай 3–4 варианта ответа в формате (а/б/в/г). Темы по порядку:
1. О каком проекте речь? Одна фраза.
2. Кто целевая аудитория? Один сегмент конкретно.
3. Какую боль вы снимаете? Одна боль.
4. Какой формат продукта? (а) лендинг + форма, (б) SaaS-приложение, (в) AI-агент / бот, (г) marketplace, (д) другое.
5. Где будете деплоить? (а) Vercel, (б) Railway, (в) Amvera, (г) ещё не решили.
6. Какой первый минимальный результат хотите увидеть через одну сессию? Одна фраза.
7. Есть ли уже бренд / тон / референсы? Если да — где взять.
8. Какие интеграции точно нужны? (LLM API, платежи, БД, аналитика).
9. Что стоп-критерий «хватит на сегодня»? (например: задеплоен лендинг, работает /api/lead).
10. Что важно НЕ трогать?

ШАГ 3. Обнови business/. Перепиши под мой ответ:
- business/INDEX.md (актуализируй карту)
- business/company/about.md
- business/products/overview.md
- business/audience/avatar.md
- business/goals/monthly.md
- business/economics/unit-economics.md (если применимо)
- business/marketing/channels.md
- business/assets/brand-guidelines.md (тон, цвета, голос)

Если данных мало — оставляй блоки «заполнить» с конкретными вопросами, не размытыми. Не выдумывай факты.

ШАГ 4. Обнови CLAUDE.md. Перепиши только разделы:
- «Что это за проект» под мой проект,
- «Стек» если меняется,
- «Правила UI» если есть бренд-референс.
Остальное не трогай.

ШАГ 5. Создай первый план. Файл plans/YYYY-MM-DD-<короткое-имя-фичи>.md по plans/TEMPLATE.md. Сегодняшнюю дату возьми из системы. План — для одной первой фичи (минимальный результат из шага 2 пункта 6). Заполни все секции. В блоке «10 причин провала» — реальные риски, не общие слова.

ШАГ 6. Запусти критику. Используй субагент critic (.claude/agents/critic.md) или прогоняй вручную: пройдись по плану и пометь проблемы. Внеси правки в план до того как покажешь его мне.

ШАГ 7. Покажи мне:
- 5-строчное summary что я получу,
- список файлов которые ты собираешься создать/изменить на следующей итерации,
- ровно один первый шаг кода/контента который ты предлагаешь сделать.

ШАГ 8. ОСТАНОВИСЬ. Жди моё «да, поехали» или правки. БЕЗ моего подтверждения не пиши код, не запускай pnpm install, не ставь зависимости, не делай git commit.

ШАГ 9. После моего «да»:
- Сделай ровно один первый шаг.
- Запиши итог в retrospectives/YYYY-MM-DD-<имя>.md по retrospectives/TEMPLATE.md.
- Обнови чекбоксы в plans/<...>.md.
- Покажи финальное дерево проекта (только верхний уровень + изменённые поддеревья) и предложи следующий шаг.

ОГРАНИЧЕНИЯ:
- Не читай .env целиком, не выводи содержимое .env.* в чат.
- Не хардкодь секреты в код. Все ключи только через переменные окружения.
- Не запускай git push, git push --force, git reset --hard, rm -rf без моего явного «да».
- Не предлагай тяжёлый стек ради красоты. Выбирай минимум, который решает шаг 2 пункт 6.
- Все ответы — на русском.

НАЧНИ С ШАГА 1.
````

## После того как агент закончит

Проверьте сами:

```bash
pnpm install
pnpm dev
scripts/doctor.ps1   # Windows
# или
scripts/doctor.sh    # macOS / Linux
```

Если что-то не запускается — откройте новую сессию Claude Code и пришлите ошибку.
