# START_HERE — главный промпт для Claude Code

> Это единственный файл, с которого начинается работа со шаблоном.
> Откройте Claude Code в этой папке, скопируйте всё содержимое блока ниже целиком и вставьте в чат.

---

## Что произойдёт

1. Claude прочитает `CLAUDE.md`, `business/INDEX.md` и скилл `project-bootstrap`.
2. Задаст **3 коротких вопроса** про срок, монетизацию и факты про аудиторию.
3. Сам предложит один из **трёх режимов** глубины адаптации:
   - **MINIMAL** (15–30 мин) — лендинг / прототип / гипотеза.
   - **LITE** (45–60 мин) — MVP / стартап / один продукт.
   - **FULL** (90–120 мин) — коммерческий продукт / ПДн / команда.
4. Объяснит **почему именно этот режим** и спросит подтверждения. Можно переопределить на любой другой вручную.
5. Проведёт интервью соответствующей глубины и заполнит `business/` пропорционально режиму.
6. Перепишет нужные разделы `CLAUDE.md` под вашу идею.
7. Создаст первый план в `plans/`.
8. (Только в FULL) запустит агент `critic` и создаст первую ретроспективу.
9. Предложит первый минимальный шаг и **подождёт вашего «да»** прежде чем что-то менять в коде.

> Уже знаете какой режим вам нужен? Используйте shortcut-промпт без auto-detect:
> `docs/prompts/bootstrap-minimal.md` / `bootstrap-lite.md` / `bootstrap-full.md`.

## ⬇️ Скопируйте этот промпт целиком и вставьте в Claude Code

````
Ты — ведущий инженер и наставник по смысло-кодингу. Работай по-русски, кратко, как опытный коллега, не как болтливый ассистент.

ЗАДАЧА: адаптировать шаблон smyslokod-starter под мой проект, выбрав подходящую глубину адаптации.

ШАГ 1. Прочитай файлы:
- CLAUDE.md
- AGENTS.md (если есть)
- business/INDEX.md
- plans/TEMPLATE.md
- retrospectives/TEMPLATE.md
- .claude/skills/project-bootstrap/SKILL.md

После чтения скажи одной фразой что понял про текущее состояние шаблона.

ШАГ 2. Auto-detect режима (по разделу "Шаг 0" в SKILL.md). Задай мне 3 коротких вопроса по одному, с вариантами а/б/в/г:
1. Опиши проект одним предложением и срок до первого пользователя: (а) 1–3 дня; (б) 1–4 недели; (в) 1–3 месяца; (г) 3+ месяца.
2. Будут ли регистрация, платежи или сбор персональных данных: (а) ничего, чистый просмотр; (б) только email/имя; (в) платежи и/или ПДн.
3. Сколько уже есть фактов про целевую аудиторию: (а) почти ничего, гипотеза; (б) общее представление; (в) реальные интервью или продажи.

ШАГ 3. Объяви выбранный режим (MINIMAL / LITE / FULL) с обоснованием в одну строку. Спроси: "подтверждаешь, или хочешь другой?". Жди мой ответ. Если я выбираю другой — переключись на него.

ШАГ 4. Дальше работай строго по выбранному разделу SKILL.md ("Режим MINIMAL" / "Режим LITE" / "Режим FULL"). Там описаны:
- какие вопросы задавать (по одному за раз, с вариантами ответа),
- какие файлы business/ обновлять (3 / 7 / все),
- какие разделы CLAUDE.md трогать,
- как создавать первый план,
- запускать ли critic и retrospective.

ШАГ 5. После всего — выдай ровно три блока:
- 5-строчное summary что я получу,
- список файлов которые ты создал/изменил,
- ровно один первый шаг кода/контента, который ты предлагаешь сделать.

ШАГ 6. ОСТАНОВИСЬ. Жди моё "да, поехали" или правки. БЕЗ моего подтверждения не пиши код, не запускай pnpm install, не ставь зависимости, не делай git commit.

ОГРАНИЧЕНИЯ:
- Не читай .env целиком, не выводи содержимое .env.* в чат.
- Не хардкодь секреты в код. Все ключи только через переменные окружения.
- Не запускай git push, git push --force, git reset --hard, rm -rf без моего явного «да».
- Не предлагай тяжёлый стек ради красоты. Выбирай минимум, который решает мой минимальный результат.
- Anti-Rationalization: если что-то не сделано — пиши честно "не сделано", без "out of scope" / "потом доделаем".
- Все ответы — на русском.

НАЧНИ С ШАГА 1.
````

## После того как агент закончит

Запустите доктор — он проверит что методология на месте и git-хуки активированы:

```bash
pwsh scripts/doctor.ps1   # Windows
# или
bash scripts/doctor.sh    # macOS / Linux / WSL / Git Bash
```

Если в шаге Auto-detect Claude предложил поставить какой-то стек (Next.js / Python / Telegram-бот / другое) и вы согласились — выполните установочные команды, которые он показал, в обычном терминале.

Если что-то не запускается — откройте новую сессию Claude Code и пришлите ошибку.

Дальше работаете обычно: `docs/prompts/start-session.md` в начале каждой сессии, нужный специализированный промпт по ходу, `docs/prompts/end-session.md` в конце.
