# Промпт: начать сессию

> Используйте в начале каждой рабочей сессии. Помогает Claude быстро войти в контекст проекта и предложить осмысленный фокус на сегодня — без «давай я перечитаю всю репу».

## Когда использовать

- Открыли проект после паузы (день / неделя / месяц).
- Не помните, чем закончили в прошлый раз.
- Хочется получить план на 1–3 часа работы, а не «давай ещё что-нибудь добавим».

## Промпт

```
Сейчас я начинаю рабочую сессию. Войди в контекст проекта и предложи фокус.

Алгоритм:

1. Прочитай:
   - CLAUDE.md (только разделы 1, 5, 10)
   - business/goals/monthly.md (текущая месячная цель)
   - последний файл в plans/ (по дате) — это активная фича
   - последний файл в retrospectives/ — что было в прошлой сессии

2. Кратко (не более 10 строк) ответь мне на 4 вопроса:
   - Что мы делаем сейчас? (в одно предложение)
   - Что было в прошлой сессии? (1–2 строки)
   - Что осталось из активного плана? (список незакрытых чекбоксов)
   - Какой следующий конкретный шаг? (одно действие)

3. Спроси меня:
   - Сколько у меня сегодня времени (15 / 60 / 180 минут)?
   - Идём по плану или есть что-то срочное?

4. После моего ответа предложи 1 (одну) конкретную задачу
   на сегодня, по объёму подходящую под мой бюджет времени.
   Без «и заодно сделаем X».

Не открывай весь business/. Не пиши код. Не ставь зависимости и не запускай dev-сервер.
Только понять состояние и согласовать фокус.

Все ответы — на русском.
```

## Что должно получиться

- 4 ответа на старте (где мы / что было / что осталось / следующий шаг).
- 2 уточняющих вопроса (время / приоритет).
- 1 предложение задачи под бюджет.

После согласования — переходите к промптам для нужного типа задачи (`debug-bug`, `add-tdd-feature`, `create-feature-plan` и т.д.).
