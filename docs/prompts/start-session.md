# Промпт: продолжаем

> Используйте в начале рабочей сессии после паузы - дня, недели, месяца. Claude находит активный план, сверяет его checkpoint с фактами и продолжает работу, а не перечитывает весь репозиторий. Это вход «Продолжаем» из `docs/workflow.md`, раздел 1.

## Когда использовать

- Открыли проект после паузы и хотите продолжить с того же места.
- Не помните, чем закончили в прошлый раз.
- Прошлая сессия оборвалась, и неясно, что успело сохраниться.

## Промпт

```
Продолжаем работу.

1. Найди план в plans/ со статусом не "завершён" и не "отменён" (TEMPLATE.md и README.md - не планы). Его нет - скажи об этом и выбери вход по разделу 1 docs/workflow.md. Статус "на ревью" - продолжи ревью по docs/prompts/run-critique.md; "заблокирован" - назови блокер и что нужно для разблокировки.
2. Прочитай checkpoint плана и сверь его с фактами: git status, коммиты после даты checkpoint, изменённые файлы. Быстрые проверки, которые checkpoint называет пройденными, перезапусти. Записанные в checkpoint запущенные процессы - проверь, живы ли и что успели сделать.
3. Ответь коротко, до 10 строк:
   - что мы делаем (одно предложение);
   - что сделано и чем подтверждено;
   - где checkpoint разошёлся с фактами;
   - что осталось и какой следующий шаг.
4. План одобрен и расхождений нет - продолжай исполнение по разделу 6 docs/workflow.md. Есть расхождение или не хватает решения - спроси только его.

Секреты не читай, весь business/ не открывай. Ответы - на русском.
```

## Что должно получиться

- Короткая сводка: где мы, что подтверждено, что разошлось, следующий шаг.
- Работа продолжается по одобренному плану без повторного старта.
- Вопрос пользователю - только о конкретном недостающем решении.
