# Промпты - карта

Готовые промпты для типовых сценариев. Открывайте нужный файл, копируйте промпт, подставляйте свои значения вместо `<ВОТ ТАКОГО>` и отправляйте агенту. Большинство сценариев агент узнаёт и без промпта - по `docs/workflow.md`; промпт полезен, когда хочется задать порядок явно.

Каждый промпт самодостаточен: «когда использовать», «когда НЕ использовать», тело промпта и «что должно получиться».

## Карта по сценариям

### Старт проекта

| Промпт | Когда | Время |
| --- | --- | --- |
| [bootstrap-project.md](./bootstrap-project.md) | Есть идея: ядро `business/INDEX.md`, глубина по риску, стек, первый план. Обычно не нужен: в свежем шаблоне агент предлагает старт сам | 15-120 мин по глубине |
| [import-existing-project.md](./import-existing-project.md) | Есть код или документ архитектуры: ядро и `CLAUDE.md` заполняются по ним и 5-7 вопросам (режим IMPORT) | 30-60 мин |

| [grill-idea.md](./grill-idea.md) | Идея есть, но нечёткая: интервью в 3 круга до проверяемого результата | 30-60 мин |

## Типовые сценарии

### Новый проект

- **Идеи нет:** напишите агенту «хочу что-то сделать» - он поможет выбрать направление и дешёвую проверку спроса; дальше `grill-idea.md`.
- **Есть идея:** напишите агенту одной-двумя фразами или используйте `bootstrap-project.md`. Глубину можно задать словами: «минимально», «по-полной».
- **Есть код или архитектура:** `import-existing-project.md`.
- **Прервались посередине:** «продолжаем» - агент восстановит состояние по ядру `business/INDEX.md` и плану.

### Типовой день

Утро: «продолжаем» (`start-session.md`).

День - агент исполняет одобренный план; отдельные промпты - по ситуации:

- новая задача M или L → `create-feature-plan.md` → `run-critique.md` → одобрение;
- баг → `debug-bug.md`;
- чистая логика → `add-tdd-feature.md`;
- UI готов → `visual-review.md`;
- хочу выкатить → `stress-test.md` → `deploy-project.md`;
- нашёл скилл или MCP → `install-skill-safely.md`.

Вечер: `end-session.md` - checkpoint, `business/`, ретроспектива при уроке.

### Глубина бизнес-контекста растёт вместе с проектом

- **MINIMAL → LITE.** Гипотеза подтвердилась - скажите агенту «углубим бизнес-контекст до LITE»: он создаст недостающие разделы из форм, не перетирая заполненное.
- **LITE → FULL.** Появились команда, ПДн или юридические документы - то же до FULL: экономика, юр. данные, конкуренты, контент.

## Связи с процессом, правилами и скиллами

- Процесс - `docs/workflow.md`: какой вход, когда план, как ревью, как исполнение.
- Правила в `.claude/rules/` - что соблюдать и в каком формате.
- Скиллы в `.claude/skills/` ведут цикл: debug-bug → diagnose, add-tdd-feature → tdd, grill-idea → grill-me, bootstrap-project и import-existing-project → project-bootstrap.
- Шаблоны `plans/TEMPLATE.md` и `retrospectives/TEMPLATE.md` - структура плана и ретроспективы.

Если промпт противоречит `docs/workflow.md` или правилу из `.claude/rules/`, выигрывают они, а противоречие сообщите автору шаблона.

## Как добавить свой промпт

1. Один файл `docs/prompts/<глагол>-<объект>.md`.
2. Структура: «Когда использовать» → «Когда НЕ использовать» → «Промпт» (в блоке кода) → «Что должно получиться».
3. Промпт пишите от своего лица к агенту. Указывайте конкретные файлы, которые надо прочитать.
4. Добавьте строку в таблицу выше.
5. Проверьте на реальной задаче и поправьте формулировки.
