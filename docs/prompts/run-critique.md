# Промпт: прогнать план через критику

```
Запусти субагент critic (.claude/agents/critic.md) на файл plans/<ИМЯ-ФАЙЛА>.md.

Цель — найти 10 причин провала, проверить риски, предложить конкретные правки. Если субагенты недоступны в этом окружении — выполни ту же работу сам по формату из .claude/agents/critic.md.

После получения критики:
1. Покажи мне найденные риски.
2. Внеси правки в план только после моего "да".
3. Не правь код.
```
