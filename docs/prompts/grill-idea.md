# Промпт: погрилить идею

> Используйте когда у вас есть нечёткая идея и хочется превратить её в проверяемый план до того, как кто-то начнёт писать код. Запускает скилл `grill-me` — интенсивное интервью на 3 круга глубины.

## Когда использовать

- В голове идея в одном-двух предложениях, нужно её прояснить.
- В черновике плана много «потом решим» / «нужно подумать».
- Метрика успеха звучит как «всё станет лучше» или «работает».
- Перед крупной фичей (L по Sizing) и непонятно, по какому пути идти.

## Когда НЕ использовать

- Вы чётко знаете, чего хотите, и формулируете задачу конкретно.
- Цейтнот: нужно «быстро прикинь, не задавая 20 вопросов».
- Мелкая правка / опечатка / стилистика.

## Промпт

```
У меня есть идея. Погрилль меня. Запусти скилл grill-me
(.claude/skills/grill-me/SKILL.md).

Идея в одном-двух предложениях: <ОПИСАНИЕ>
Срочность: <"быстро на 30 минут" / "обсуждаем глубоко">

Алгоритм для тебя:

1. Сначала прочитай:
   - business/INDEX.md
   - business/audience/avatar.md
   - business/goals/monthly.md

2. Веди интервью по 3 кругам, ОДИН вопрос за раз:

   Круг 1 — суть. Что именно? Кто пользователь? Что меняется в его жизни?
            Какая боль из avatar.md закрывается?

   Круг 2 — границы. Что НЕ входит? Минимально жизнеспособная версия?
            Что считается "достаточно" для первой итерации?

   Круг 3 — реальность. Какая ОДНА цифра скажет, что сработало?
            Что может пойти не так? Сколько готов потратить времени?
            На какую цель из goals/monthly.md это работает?

3. Не переходи в следующий круг, пока в текущем нет ясности.
   Если ответ нечёткий ("удобно", "быстро", "мобильный") — переспроси.

4. После 3 кругов — выдай:
   - Резюме идеи в 5 строк (для моего подтверждения).
   - Список acceptance criteria (что будет проверяться).
   - Список "не сейчас" (что осознанно отложили).
   - Один пункт неясности, если остался — открыто признай его.

5. Спроси меня: создавать ли plans/YYYY-MM-DD-<имя>.md
   по результатам интервью. Если да — создай по plans/TEMPLATE.md
   и заполни ВСЕ блоки, особенно Challenge Loop (блок 9)
   и метрику успеха (блок 8 — одна цифра).

Не пиши код. Не запускай pnpm. Не делай git commit.
Anti-Rationalization: если на каком-то вопросе я говорю "потом
разберёмся" — это сигнал, что нужен ещё круг, а не пропуск.

Все ответы — на русском.
```

## Что должно получиться

- Серия вопросов в формате один-вопрос-один-ответ.
- 5-строчное резюме идеи в конце.
- Список acceptance criteria.
- Список «не сейчас».
- (Опционально, по согласованию) — файл `plans/YYYY-MM-DD-<имя>.md` с заполненным Challenge Loop.

## После

Если идея превратилась в план — следующий промпт `run-critique.md` (прогнать через скилл `critic`), потом `add-tdd-feature.md` или обычная фазовая реализация.
