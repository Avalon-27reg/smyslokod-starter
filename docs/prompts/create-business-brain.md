# Промпт: создать бизнес-мозг с нуля

> Используйте если есть проект, но `business/` пустой / устаревший, и хочется быстро его наполнить.

```
Прочитай business/INDEX.md и .claude/rules/business-context.md.

Я расскажу про мой проект свободным текстом — после моего ответа извлеки факты и аккуратно разложи их по соответствующим файлам в business/. Правила:

1. Не выдумывай. Если факта нет — оставь блок "🔲 заполнить:" с конкретным вопросом ко мне.
2. Не клади один факт в два файла.
3. Файлы держи короткими. Большие списки разбивай на бул-пойнты.
4. После раскладки — покажи мне дифф (какие файлы и какие блоки изменились).
5. Не коммить.

Готов? Тогда задай мне один открытый вопрос: «расскажи про твой проект как другу за 5 минут».
```
