# Промпт: закрыть сессию

> Используйте в конце каждой рабочей сессии — даже если работа не доделана. Это формат «завершения сессии» из CLAUDE.md §10, упакованный в один промпт.

## Когда использовать

- Закончили на сегодня и хотите оставить чистое состояние для следующей сессии.
- Что-то не доделали — нужно зафиксировать «вот тут остановились».
- Узнали новое про проект — нужно перенести из чата в `business/`, пока не забылось.

## Промпт

```
Закрываем сессию. Сделай по чек-листу из CLAUDE.md §10.

Алгоритм:

1. Активный план в plans/<...>.md:
   - Обнови чекбоксы [ ] → [x] по фактически сделанному.
   - Если изменился подход — поправь раздел "Дизайн решений".
   - Если появились новые риски — добавь их в "10 причин провала".
   - Если фаза завершена — заполни блок "10. Self-Audit".

2. Создай retrospectives/YYYY-MM-DD-<короткое-имя>.md
   по retrospectives/TEMPLATE.md. Формат:
   - задача → как решали → было / стало → решено? → что запомнить → что можно было лучше.
   - Это память для будущих сессий, а не отчёт.

3. Если в этой сессии узнали что-то про проект (про аудиторию,
   цены, конкурентов, бренд, цели) — обнови соответствующий
   файл в business/ точечно. Не складывай знание в чат.
   Список того, что обновил — покажи мне.

4. В конце выдай ровно 4 строки:
   - Сделано: <короткий список>
   - Не сделано: <короткий список>
   - Следующий шаг: <одно действие>
   - Что обновлено: <plans/..., retrospectives/..., business/...>

Не делай git commit. Не пиши код. Не запускай build.
Anti-Rationalization: если что-то не доделано — пиши честно
"не сделано", без "pre-existing" / "out of scope" / "потом".

Все ответы — на русском.
```

## Что должно получиться

- Активный план обновлён (чекбоксы, риски, Self-Audit если завершилась фаза).
- Создан файл `retrospectives/YYYY-MM-DD-<имя>.md`.
- Точечно обновлены файлы в `business/` (если было что обновить).
- 4-строчное summary в чат.

## После

Если работа доделана — следующий шаг отдельный коммит / ревью / деплой.
Если не доделана — в следующей сессии запускайте `start-session.md`, и Claude сам подхватит контекст из обновлённого плана и ретроспективы.
