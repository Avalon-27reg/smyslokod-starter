# Промпт: bootstrap MINIMAL — прототип / лендинг / гипотеза

> Используйте когда вы точно знаете: проект — это лендинг, прототип на 1–3 дня, инструмент на день или быстрая проверка гипотезы. Без платежей, без ПДн, аудитория пока гипотеза. Если не уверены — берите [bootstrap-project.md](./bootstrap-project.md), он сам выберет режим.

## Когда использовать

Любое из:

- Лендинг под одну форму или один CTA.
- Прототип, который выкинут через неделю если гипотеза не подтвердится.
- Внутренний инструмент / pet project.
- Срок до первого пользователя — 1–3 дня.
- Нет регистрации / платежей / ПДн.

## Когда НЕ использовать

- Будут платежи, регистрация, сбор персональных данных → берите LITE или FULL.
- Срок до первого пользователя 2+ недели → берите LITE.
- Уже есть реальные интервью / аудитория / факты → берите минимум LITE.
- Несколько продуктов или сегментов → FULL.

## Время и объём

- **15–30 минут**, 3–4 вопроса.
- Заполняется только 3 файла `business/`: `products/overview.md`, `audience/avatar.md` (мини), `goals/monthly.md` (мини).
- Один план на 1–3 дня. 5 рисков (не 10).
- Критика опциональна.

## Промпт

```
Запусти скилл project-bootstrap (.claude/skills/project-bootstrap/SKILL.md)
сразу в режиме MINIMAL. Auto-detect пропусти, я знаю что хочу прототип.

Алгоритм по разделу "Режим MINIMAL" в SKILL.md:

1. Прочитай: CLAUDE.md, business/INDEX.md, plans/TEMPLATE.md, SKILL.md.

2. Задай мне 3–4 вопроса по одному:
   - Что это и для кого (одна фраза в формате "<что> для <кого>, чтобы <боль>").
   - Какой первый видимый результат хочу получить за 1 сессию (одна фраза).
   - Где будет хоститься (Vercel / Railway / Amvera / пока локально).
   - Что важно НЕ трогать (если ничего — пропусти).

3. Обнови ТОЛЬКО эти 3 файла business/:
   - products/overview.md (один абзац для лендинга).
   - audience/avatar.md (только "Кто это" + "Главная боль").
   - goals/monthly.md (главная цель = ответ 2).

   В остальных файлах business/ оставь существующие "🔲 заполнить:"
   с пометкой "не нужно для прототипа, заполнить если перерастёт в LITE".

4. Обнови CLAUDE.md только раздел "1. Что это за проект".

5. Создай plans/YYYY-MM-DD-<короткое-имя>.md по plans/TEMPLATE.md.
   Минимальный результат = ответ 2. Допускается 5 причин провала вместо 10.

6. Покажи мне:
   - 5-строчное summary что я получу.
   - Список изменённых/созданных файлов.
   - Один конкретный первый шаг.

7. Остановись. Жди "да, поехали" прежде чем писать код.

Не запускай critic (для MINIMAL опционально).
Не коммить. Не push. Все ответы — на русском.
```

## Что должно получиться

- Заполнены 3 файла в `business/`.
- Раздел 1 в `CLAUDE.md` обновлён.
- План `plans/YYYY-MM-DD-<имя>.md` создан с 5 рисками.
- Claude остановился и ждёт «да».

## После

Если гипотеза подтвердится и проект захочется развивать — запустите `bootstrap-lite.md` (он дозаполнит то, что в MINIMAL пропущено).
