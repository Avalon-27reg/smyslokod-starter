# Промпт: починить баг

> Используйте при репорте бага. Запускает скилл `diagnose` — систематический цикл отладки вместо «попробую переустановить и закомментировать».

## Когда использовать

- Что-то «не работает» / «упало» / «странно ведёт себя».
- Тест красный, причина не очевидна.
- После недавнего рефакторинга появилась регрессия.

## Когда НЕ использовать

- Очевидная опечатка / синтаксическая ошибка — просто чините.
- Вы уже знаете причину и хотите конкретную правку — пишите её напрямую.

## Промпт

```
У меня баг. Запусти скилл diagnose (.claude/skills/diagnose/SKILL.md)
и проведи меня по 5 шагам.

Симптом: <ОПИШИТЕ ЧТО ПРОИСХОДИТ — что нажали / что ожидали / что увидели>
Окружение: <dev / прод, браузер, версия Node, нужные данные>
Что я уже пробовал: <если что-то пробовали — перечислите>

Алгоритм для тебя:

1. Repro:
   - Если шагов воспроизведения недостаточно — спроси одним вопросом.
   - Если repro нестабильный — остановись, скажи мне об этом.
   - Не двигайся дальше без воспроизводимого сценария.

2. Минимизация:
   - Урежь сценарий до 5–20 строк, которые ломаются.
   - Покажи минимальный repro в чате.

3. Гипотеза:
   - Сформулируй ОДНУ конкретную гипотезу: "я думаю это X, потому что Y".
   - Скажи, какой эксперимент за 1–2 минуты её подтвердит / опровергнет.

4. Инструментирование:
   - Перед правкой — добавь логи / breakpoints / console.log так,
     чтобы УВИДЕТЬ значения в точке расхождения.
   - Покажи мне, что увидел.

5. Исправление:
   - Минимальная правка, чинящая ПРИЧИНУ, не симптом.
   - Если возможно — напиши тест, который ловит этот баг.
   - Прогони repro — должно стать зелёным.
   - Импакт-анализ в миниатюре: 1–2 ближайших сценария проверь руками.
   - Убери добавленные console.log.

В конце — короткий отчёт по формату из SKILL.md:
симптом / причина / правка / проверка / регрессия-чек.

Anti-Rationalization: запрещено "обернул в try/catch — стало тише",
"закомментировал блок — пропало", "может в зависимостях что-то".
Чиним причину, а не выключаем сигнал.

Не делай git commit. Все ответы — на русском.
```

## Что должно получиться

- Минимальный repro в чате.
- Конкретная причина (одна строка).
- Минимальная правка с указанием `файл:строка`.
- Проверка, что repro теперь зелёный.
- Список соседних сценариев, проверенных руками.
- (Опционально) тест, ловящий этот баг.
