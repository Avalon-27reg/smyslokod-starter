# Промпт: bootstrap LITE — MVP / стартап на коленке

> Используйте если у вас MVP с понятной аудиторией, какой-то монетизацией и каналами привлечения, на 1–4 недели. Один продукт + одна аудитория. Если не уверены — берите [bootstrap-project.md](./bootstrap-project.md), он сам выберет режим.

## Когда использовать

Любое из:

- MVP, который потенциально станет продуктом.
- Стартап «на коленке» — один основатель, один продукт, одна аудитория.
- Срок до первого пользователя — 1–4 недели.
- Возможно нужны email-регистрация / простые платежи (но без сложной экономики).
- Уже есть общее представление об аудитории, но не реальные интервью.

## Когда НЕ использовать

- Прототип на день / лендинг → берите MINIMAL.
- Несколько сегментов, ПДн, юр. документы, серьёзная экономика → берите FULL.
- Никакой идеи кроме «хочу что-то сделать» → сначала [grill-idea.md](./grill-idea.md).

## Время и объём

- **45–60 минут**, 6–7 вопросов.
- Заполняется ~7 файлов `business/`: products/overview, products/pricing, audience/avatar, audience/objections, goals/monthly, marketing/channels, assets/brand-guidelines (мини).
- Один план + полный блок «10 причин провала».
- Критика — по желанию пользователя.

## Промпт

```
Запусти скилл project-bootstrap (.claude/skills/project-bootstrap/SKILL.md)
сразу в режиме LITE. Auto-detect пропусти, я знаю что хочу MVP.

Алгоритм по разделу "Режим LITE" в SKILL.md:

1. Прочитай: CLAUDE.md, business/INDEX.md, plans/TEMPLATE.md, SKILL.md.

2. Задай мне 6–7 вопросов по одному, с вариантами а/б/в/г где можно:
   - О каком проекте речь (одна фраза).
   - Кто целевая аудитория (один сегмент: роль + контекст).
   - Какую боль снимаем (одна боль).
   - Формат продукта: (а) лендинг + форма; (б) SaaS; (в) AI-агент / бот; (г) marketplace; (д) другое.
   - Монетизация: (а) бесплатно / лидген; (б) разово; (в) подписка; (г) ещё не знаю.
   - 1–2 канала привлечения (Instagram, SEO, рассылка, прямые продажи и т.д.).
   - Какой первый минимальный результат за 1 сессию.

3. Обнови эти ~7 файлов business/:
   - products/overview.md (описание + формат + один абзац для лендинга).
   - products/pricing.md (модель оплаты, если применимо).
   - audience/avatar.md (полный блок).
   - audience/objections.md (3 главных возражения, если знаешь).
   - goals/monthly.md (цель месяца + одна метрика).
   - marketing/channels.md (1–2 канала).
   - assets/brand-guidelines.md (мини: тон, цвета, эмодзи если есть).

   НЕ трогай: economics/, company/legal.md, marketing/competitors.md,
   marketing/content.md — оставь существующие "🔲 заполнить:".

4. Обнови CLAUDE.md разделы 1, 2 (стек если меняется), 9 (UI если есть бренд).

5. Создай plans/YYYY-MM-DD-<имя>.md по plans/TEMPLATE.md.
   Минимальный результат = ответ 7. Полный блок "10 причин провала".

6. Покажи мне:
   - 5-строчное summary что я получу.
   - Список изменённых/созданных файлов.
   - Один конкретный первый шаг.

7. Спроси: запускать ли субагент critic для прогона плана? (для LITE
   это опционально, по моему ответу).

8. Остановись. Жди "да, поехали" прежде чем писать код.

Не коммить. Не push. Все ответы — на русском.
```

## Что должно получиться

- Заполнены 7 файлов в `business/`.
- Разделы 1, 2, 9 в `CLAUDE.md` обновлены.
- План `plans/YYYY-MM-DD-<имя>.md` создан с 10 рисками.
- (Опционально) пройдена критика плана.
- Claude остановился и ждёт «да».

## После

Если проект перерастёт в коммерческий продукт — запустите `bootstrap-full.md`, он дозаполнит экономику, юр. контекст, конкурентов, content стратегию.
