# Промпт: создать план фичи

```
Создай план новой фичи: <ОПИСАНИЕ ОДНИМ ПРЕДЛОЖЕНИЕМ>.

Алгоритм:
1. Прочитай CLAUDE.md, .claude/rules/planning.md, plans/TEMPLATE.md.
2. Прочитай business/goals/monthly.md и business/audience/avatar.md — поставь фичу в контекст текущей цели и боли клиента.
3. Создай файл plans/YYYY-MM-DD-<короткое-имя-фичи>.md по шаблону.
4. Заполни ВСЕ секции, особенно:
   - "Дизайн решений" с альтернативами,
   - "10 причин провала" — реальные риски, не общие слова,
   - "Метрика успеха" — одна конкретная цифра.
5. После создания плана покажи его мне и подожди мою реакцию.

Не запускай реализацию пока я не одобрю план.
```
