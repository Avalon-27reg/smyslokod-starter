# Промпт: подключить шаблон к проекту с готовым кодом

> Используйте, когда код или документ архитектуры уже есть, а ядро `business/INDEX.md` ещё пустое. Claude прочитает код, README, схему данных и документы, задаст 5-7 уточняющих вопросов и заполнит ядро и `CLAUDE.md` по тому, что реально работает. Это режим IMPORT скилла `project-bootstrap`.

## Когда использовать

- Проект работает или почти работает, а методологию подключаете сейчас.
- Файлы шаблона скопированы в папку с существующим кодом.
- Есть документ архитектуры, по которому ещё не начали писать код.

## Когда НЕ использовать

- Кода и архитектуры нет, есть только идея → [bootstrap-project.md](./bootstrap-project.md).
- Код о продукте ничего не говорит (заготовка, учебный проект) → [create-business-brain.md](./create-business-brain.md), рассказ своими словами.

## Промпт

```
Запусти скилл project-bootstrap (.claude/skills/project-bootstrap/SKILL.md) в режиме IMPORT.
Код проекта лежит в корне этого репо (или по пути: <ПУТЬ>). Документ архитектуры: <ПУТЬ, если есть>.

Веди по разделу "Режим IMPORT". Вопросы - по одному, варианты ответа собирай из того, что увидел в коде.

Код не меняй. В конце покажи план следующего шага и жди моего одобрения. Ответы - на русском.
```

## Что должно получиться

- Абзац-картина проекта: что делает, для кого, что сделано и что только обещано, есть ли платежи, на каком стеке.
- Проверена приватность, ядро `business/INDEX.md` заполнено по коду и ответам; факты из кода помечены как факты о коде.
- `CLAUDE.md`, раздел 2: фактический стек и команды сборки, тестов и линтера.
- Reality Check: 2-3 пробела в проекте.
- План по главному пробелу в `plans/`, Claude ждёт одобрения.

## После

Проверьте ядро и разделы `business/`: что-то Claude угадал, что-то нет - поправьте. Допишите то, чего в коде не видно: цели, конкурентов, прогноз.
