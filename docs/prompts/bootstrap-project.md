# Промпт: старт проекта

> Используйте, если Claude не предложил старт сам или вы хотите заново адаптировать шаблон. Обычно не нужен: в свежем шаблоне достаточно написать, с чем вы пришли. Ведёт скилл `project-bootstrap`: вход по фактам, вопросы только о пробелах, глубина по риску.

## Глубина

- **MINIMAL** - лендинг, прототип, гипотеза на 1-3 дня: ядро `business/INDEX.md` и 1-2 раздела.
- **LITE** - MVP, один продукт и одна аудитория: ядро и около 7 разделов, Reality Check.
- **FULL** - коммерческий продукт, платежи или ПДн, команда: все применимые разделы, Reality Check.

Скилл предложит глубину сам. Уже знаете - скажите словами: «минимально», «по-полной». Код уже есть - [import-existing-project.md](./import-existing-project.md).

## Промпт

```
Запусти скилл project-bootstrap (.claude/skills/project-bootstrap/SKILL.md) и веди по его шагам 1-7.

Что у меня есть: <ИДЕЯ ОДНИМ-ДВУМЯ ПРЕДЛОЖЕНИЯМИ / ПУТЬ К КОДУ / ПУТЬ К ДОКУМЕНТУ АРХИТЕКТУРЫ>.
Глубина: <если знаю: минимально / MVP / по-полной; иначе предложи сам>.

В конце покажи план и жди моего одобрения. Ответы - на русском.
```

## Что должно получиться

- Проверена приватность репозитория, результат записан в ядро.
- Ядро `business/INDEX.md` заполнено, открытые вопросы записаны.
- Разделы `business/` созданы из форм только там, где есть данные.
- Стек записан в `CLAUDE.md`, ничего не установлено.
- Первый план результата в `plans/`, после ревью с судьёй или с записанной причиной пропуска.
- Claude ждёт одобрения плана.
