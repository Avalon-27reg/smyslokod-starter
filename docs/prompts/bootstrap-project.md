# Промпт: bootstrap нового проекта (авто-выбор глубины)

> Используйте если хотите перезапустить адаптацию шаблона с нуля. Аналог `START_HERE.md`, но без обвязки. Скилл сам определит, нужен ли вам **MINIMAL / LITE / FULL** режим, на основе 3 коротких вопросов про срок, монетизацию и факты про аудиторию. Можно переопределить вручную.

## Когда какой режим

- **MINIMAL** (15–30 мин, ~3 файла business/) — лендинг, прототип, проверка гипотезы, инструмент на день.
- **LITE** (45–60 мин, ~7 файлов business/) — MVP, стартап на коленке, один продукт + одна аудитория.
- **FULL** (90–120 мин, все 7 блоков business/) — коммерческий продукт, ПДн / платежи, несколько сегментов.

Если уверены в режиме — используйте shortcut-промпты:
[bootstrap-minimal.md](./bootstrap-minimal.md), [bootstrap-lite.md](./bootstrap-lite.md), [bootstrap-full.md](./bootstrap-full.md).

## Промпт

```
Ты — ведущий инженер. Адаптируй шаблон smyslokod-starter под мой проект.

Запусти скилл project-bootstrap (.claude/skills/project-bootstrap/SKILL.md).

Алгоритм:

1. Прочитай: CLAUDE.md, business/INDEX.md, plans/TEMPLATE.md, и сам SKILL.md.

2. Сначала Auto-detect режима. Задай мне 3 коротких вопроса
   из шага 0 в SKILL.md (срок, платежи/ПДн, факты про аудиторию).
   После ответов:
   - Назови выбранный режим (MINIMAL / LITE / FULL).
   - Объясни почему одной строкой.
   - Спроси: "подтверждаешь, или хочешь другой?".

3. Дальше — по выбранному режиму из SKILL.md:
   - MINIMAL: 3–4 вопроса, обновить 3 файла business/, один план.
   - LITE: 6–7 вопросов, обновить ~7 файлов business/, один план + 10 рисков.
   - FULL: 10+ вопросов, все 7 блоков business/, план + critic + первая ретроспектива.

4. После заполнения business/ обнови CLAUDE.md (только указанные в режиме разделы).

5. Создай план в plans/YYYY-MM-DD-<имя>.md по plans/TEMPLATE.md.

6. Покажи 5-строчное summary, список изменений, один первый шаг.

7. Остановись. Жди явное "да, поехали" прежде чем писать код.

Все ответы — на русском. Ничего не push'и в git. Не делай git commit без согласования.
```

## Что должно получиться

- Один из трёх режимов выбран и подтверждён.
- Заполнены файлы `business/` пропорционально режиму (3 / 7 / все).
- Обновлены нужные разделы `CLAUDE.md`.
- Создан первый план `plans/YYYY-MM-DD-<имя>.md`.
- (Только для FULL) запущена критика и создана первая ретроспектива.
- Claude остановился и ждёт «да».
