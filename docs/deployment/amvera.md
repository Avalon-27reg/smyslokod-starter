# Деплой на Amvera

Amvera — российская облачная платформа. Хостинг в РФ, что важно для соответствия 152-ФЗ при работе с ПДн российских пользователей.

## Когда выбирать

- Целевая аудитория — РФ, и вы собираете персональные данные (имя, email, телефон).
- Нужно соответствие 152-ФЗ.
- Принимаете платежи через российские эквайринги.

## Когда НЕ выбирать

- Глобальная аудитория без RU-привязки — Vercel удобнее и быстрее по сети.
- Нужна edge-доставка по всему миру — Vercel / Cloudflare.

## Быстрый старт

1. Зарегистрируйтесь: https://amvera.ru
2. Создать проект → выберите тип «Приложение».
3. Способ загрузки: Git (привязать репозиторий через `amvera.yml`) или прямой push в Amvera Git.
4. Создайте `amvera.yml` в корне (см. ниже).
5. Перенесите переменные окружения через UI («Переменные окружения»).
6. Запустите сборку.

## Файл `amvera.yml` для Next.js

> 🔲 после первого деплоя сверьте формат с актуальной документацией Amvera — они меняют схему. Шаблонный пример:

```yaml
meta:
  environment: node
  toolchain:
    name: node
    version: 22
build:
  image: node:22
  pre:
    - npm install -g pnpm@10
  command: pnpm install --frozen-lockfile && pnpm build
  artifacts:
    - .next
    - public
    - package.json
    - pnpm-lock.yaml
    - node_modules
run:
  persistenceMount: /data
  containerPort: 3000
  command: pnpm start
```

## Переменные окружения

Все из `.env.example`. Ставите через панель Amvera. Они доступны в `process.env.*` во время билда и рантайма.

## Постоянные данные

Если приложение пишет на диск (загрузка файлов, SQLite), монтируйте `persistenceMount`. Postgres лучше держать как отдельную managed-БД.

## Платежи

- Юр. лицо / ИП обязательны для подключения российских эквайрингов.
- Тестовые ключи провайдера — для DEV-окружения.
- Webhooks от ЮKassa / CloudPayments — обязательно валидируйте подпись.

## 152-ФЗ — мини-чеклист

- [ ] Хостинг в РФ (Amvera ✅).
- [ ] Уведомление в Роскомнадзор о начале обработки ПДн.
- [ ] На сайте: Политика конфиденциальности + согласие на обработку ПДн (отдельный чекбокс).
- [ ] Cookie-уведомление.
- [ ] Не передаём ПДн за пределы РФ без согласия пользователя.

См. `business/company/legal.md`.

## Откат

В UI Amvera → Деплои → выбираете предыдущий → «Восстановить».

## Логи

В UI → Логи. Доступны логи приложения и сборки.

## Если что-то идёт не так

| Симптом | Причина | Решение |
| ------- | ------- | ------- |
| Сборка длится > 10 мин | большие зависимости | уменьшите образ, используйте кэш зависимостей |
| 502 после деплоя | `containerPort` не совпадает с тем, на котором слушает Next.js | по умолчанию Next слушает 3000 — этот же порт ставьте в `amvera.yml` |
| Не подхватывает env | переменные не сохранились через UI | пересохраните в панели и сделайте redeploy |

## Альтернативы в РФ

- Selectel — IaaS, нужен DevOps.
- Yandex Cloud — Container Solution для контейнеров.
- VK Cloud — managed Kubernetes.

Если бизнес растёт — стоит сравнивать. Для старта Amvera проще всего.
