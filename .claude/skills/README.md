# .claude/skills/

Скиллы — это «навыки» Claude Code, которые подгружаются автоматически когда задача подходит под их `description`. Каждый скилл — папка с файлом `SKILL.md`.

## Текущие скиллы

- [`project-bootstrap/`](./project-bootstrap/SKILL.md) — адаптация шаблона `smyslokod-starter` под новый проект пользователя.

## Как добавить свой скилл

1. Создайте папку `имя-скилла/`.
2. Внутри — `SKILL.md` с frontmatter:

```markdown
---
name: имя-скилла
description: Когда использовать (одно предложение, не больше). Пример «Use this when…»
---

# Имя скилла

## Когда применять

(условия активации)

## Что делать

(пошаговая инструкция)

## Что вернуть

(формат ответа)
```

3. Не делайте скиллы на «всё подряд». Один скилл = одна узкая задача.
4. `description` — главное. По нему Claude решает, активировать ли скилл.

См. документацию: https://docs.claude.com/en/docs/claude-code/skills
