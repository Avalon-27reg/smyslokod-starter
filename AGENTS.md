# AGENTS.md - вход для Codex и других агентов

> Claude Code: этот файл для других агентов, всё нужное уже загружено через `CLAUDE.md`.

1. Прочитай `CLAUDE.md` - карта проекта. Строка `@docs/workflow.md` в нём - импорт для Claude Code; для тебя это ссылка на тот же файл.
2. Прочитай `docs/workflow.md` - процесс работы, общий для всех агентов.
3. Правила из таблицы в разделе 4 `CLAUDE.md` Claude Code получает автоматически, ты читаешь их сам: `security.md` и `git.md` - в начале каждой сессии, остальные - когда задача касается их темы.
4. Скиллы `.claude/skills/<имя>/SKILL.md` для тебя - обычные инструкции: задача совпала с описанием скилла - прочитай его и веди работу по нему.
5. Роли `.claude/agents/*.md` - для независимого ревью; как обойтись без субагентов - `docs/workflow.md`, раздел 5.

Порядок старшинства файлов - в начале `docs/workflow.md`.
