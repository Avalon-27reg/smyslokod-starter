# Бренд-гайдлайны

> 🔲 заполнить при адаптации проекта. Этот файл — главный источник для UI и копи. Claude Code читает его перед версткой и текстами.

## Голос и тон

- Тон: (профессиональный / дружеский / экспертный / ироничный / прямой)
- Уровень формальности: (на «вы» / на «ты» / смешанный)
- Юмор: (да / нет, какой)
- Эмодзи: (никогда / умеренно / часто) и где

## Слова, которые мы используем

10–20 слов и фраз, которые звучат «как мы». Эти слова Claude должен класть в копию первыми.

## Слова, которые мы НЕ используем

Стоп-лист. Канцеляризмы, маркетинговые штампы, неуместные англицизмы — что именно для нашего бренда «нельзя».

## Примеры «как мы пишем»

Скопируйте 3–5 коротких блоков текста из вашего сайта/email/постов как образцы. Это эталон тона.

```
Пример 1: ...

Пример 2: ...
```

## Антипримеры

Тексты «не наши». Из конкурентов или из старых версий, которые решили убрать.

```
Антипример 1: ...
```
